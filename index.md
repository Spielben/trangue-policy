Privacy Policy for Trangue
Last updated: September 30, 2026

Trangue is a private personal assistant operated by Spielben & Co for the exclusive use of its owner. It is not offered to the public.

1. Google Data Accessed
With the owner's explicit consent, Trangue accesses the following Google data through Google OAuth:

Google Calendar (https://www.googleapis.com/auth/calendar): to read, create, update and delete calendar events and reminders on the owner's behalf.

Google Drive (https://www.googleapis.com/auth/drive.file): to upload and share files created by Trangue (for example, quotation PDFs). Trangue can only access files it created or files the owner explicitly opened with it.

2. How the Data Is Used
Google user data is used solely to perform the calendar and file tasks requested by the owner. It is not used for advertising, profiling, or any purpose unrelated to these tasks.

To understand requests, Trangue relies on third-party AI language model providers. Calendar or file information needed to answer a request may be sent to these providers for that purpose only.

3. Data Sharing
We do not sell, rent, or share Google user data with third parties, except with the service providers strictly needed to run the assistant, as described above.

Trangue's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Data Storage and Retention
The OAuth access token is stored on a private server with access restricted to the operator. Calendar events and files remain in the owner's Google account. Access can be revoked at any time at https://myaccount.google.com/permissions.

5. Contact Us
If you have any questions regarding this privacy policy, please contact us at spielben@gmail.com.
